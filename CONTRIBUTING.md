# Contributing to Little Wild

Thank you for helping keep Little Wild free and kind to children.

1. Keep the interface usable without reading and without spoken instructions.
2. Preserve the rule that every stage needs both listening and speaking practice.
3. Do not add ads, purchases, accounts, analytics, tracking, or new child-data collection.
4. Keep animal roles in `web/content.js` and game rules in the learning modules.
5. Run `npm run check` before opening a pull request.

Check visual changes in a small phone-sized viewport. For microphone changes, test permission denial, a cancelled recording, silence, a wrong letter, and a correct letter on a real device.

By contributing, you agree that your contribution may be distributed under GPL-3.0-only. Only include artwork, sound, fonts, or code that you are allowed to redistribute under compatible terms, and document its source in `THIRD_PARTY.md`. Do not commit keys, APKs/AABs, recordings, or real child data.
