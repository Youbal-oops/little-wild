# Security policy

Little Wild is intended for children. Please report a possible vulnerability privately through the repository host’s private-security-advisory feature when it is enabled. Until a maintainer contact is published, do not include child information, recordings, screenshots with personal data, or exploit details in a public issue.

Reports involving the microphone bridge, local assets, WebView navigation, permissions, or accidental data transmission are especially important. Before a public release, the maintainers must publish a monitored security contact and disclosure process.
